# Pawz

Pet health record web app. Full product spec lives in `SPEC.md` in this directory — read it for vision, personas, and feature scope before making product decisions.

## UI Placement Rules
When adding or moving UI elements, restate the exact placement in words (parent container, corner/edge, and what it sits above/below) BEFORE editing the HTML. If the placement is ambiguous, ask one clarifying question instead of guessing.

## Prototype Conventions
Prototypes are single-file HTML with inline CSS/JS unless told otherwise. Keep the whole prototype in one file so it can be opened directly in a browser, and preserve existing class names and layout structure when making refinements.

## Handoff Docs
Every prototype session ends with a Markdown handoff note containing: what was built, key design decisions, known gaps, and next steps. Update the existing handoff file rather than creating a new one.
